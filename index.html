Share with your partner off

Start a shared calendar here, then send the invite link to the one person you're sharing with. Changes show up on both of your devices within a few seconds. Your calendar is stored online under a long random room code: anyone with the link can see and change it, so send it only to them.

Use your own Supabase project instead

Paste the two values from your project (Settings → API) and a room code you both use. The table needs to be called schedules, with id (text), data (jsonb) and updated_at (timestamptz).

Job calendars

If your work scheduler can publish your shifts as a calendar link (WhenToWork calls it Export to Personal Calendar, most others say iCal, Subscribe or webcal), paste that link here. Shifts then appear by themselves and update when the rota changes. These blocks are owned by the feed: a shift dropped at work disappears here too, so do not hand-edit them.
